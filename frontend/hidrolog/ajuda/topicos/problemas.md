# Problemas comuns

**Esqueci a senha.** Peça ao master: ele define uma senha nova na página Usuários. Se quem
esqueceu foi o próprio master, veja [Instalação, dados e cópias de segurança](ajuda:instalacao).

**"Login ou senha incorretos, ou usuário desativado."** Confira maiúsculas e minúsculas. Se
estiver certo, o seu usuário pode ter sido desativado: fale com o master.

**O tipo de sensor que eu preciso não aparece em "Novo equipamento".** O plugin desse tipo não
está instalado ou está desativado. O master instala em Configurações → Plugins (veja
[Plugins de sensor](ajuda:plugins)).

**A importação recusou os arquivos.** O plugin explica o motivo (por exemplo, "nenhum arquivo
de dados encontrado"). Confira se escolheu a pasta certa e o equipamento do tipo certo.

**Importei o mesmo cartão duas vezes.** Não tem problema: nada é duplicado.

**O .rar não abre.** Falta o programa de descompactação no computador (veja
[Importar dados](ajuda:importar)).

**Um equipamento ficou só com as abas comuns e não aceita importação.** O plugin do tipo dele foi
desativado ou removido. Os dados continuam no banco; reativar o plugin traz as abas e a
importação de volta.

**Um equipamento sumiu da lista.** Ele pode ter sido desativado: marque **Mostrar desativados**
em Equipamentos.

**Apareceu uma mensagem de erro.** A mensagem na tela é um resumo. Os detalhes técnicos ficam no
arquivo de log (`hidrolog.log`, na pasta de dados do app). Envie esse arquivo para quem cuida
da instalação.

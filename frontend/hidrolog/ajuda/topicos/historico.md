# Histórico de envios

Cada importação vira um **envio**, registrado com data, usuário, equipamento, origem dos
arquivos e as contagens de leituras (novas, duplicadas, corrompidas, ignoradas).

- A página **Histórico de envios** lista todos os envios, do mais recente para o mais antigo.
  Use a busca para filtrar por equipamento, usuário ou origem.
- Selecione um envio e clique em **Ver detalhe** (ou clique duas vezes) para ver o período
  coberto, a duração, os avisos e os arquivos ignorados.
- A aba **Envios** da página do equipamento mostra só os envios daquele equipamento.
- Em **Minha conta** aparecem os seus últimos envios.

O histórico é só de consulta: ele serve para saber quem enviou o quê e quando, e para conferir
se um cartão já foi importado.
